# ESPER Focus

Retro terminal pomodoro timer (Electron).

Run locally:   npm install && npm start
Windows build: push this folder to GitHub, then Actions > build-windows > Run workflow.
               Download the installer and portable .exe from the run's artifacts.

In the app: F11 fullscreen, ctrl+alt+space starts/pauses from any window, type `help` at the prompt.
Ambience: app/assets/ambient.ogg (6-minute loop, crossfaded in code). Replace the file to change it.

Sounds: ambience loop (app/assets/ambient.ogg) and the end-of-phase chime (cut from the same recording; app/sfx.js).
Crew chat: edit the CONV list in app/index.html to change what the characters say.
